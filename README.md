# React essentials
This project contains basic features of React like 
1. How do components in React be made?
2. How to pass data between two components?
3. How to handle Props, State, Events in React ?

# Requirements for this Project 
1. Need to install the latest **Node.js** in your system
2. Run command **npm create vite@latest** in your system where you want your project
   - It will ask for framework select **React.js** and it will ask for language select **JavaScript** there
3. You can run the project by running **npm run dev** command in your project terminal.
